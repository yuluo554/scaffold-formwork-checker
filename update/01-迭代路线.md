# scaffold-formwork-checker · 迭代路线（v1.0.0 → v2.0.0）

> 前提：`00-诊断报告.md` 的 D1–D9 已实测确认。
> 与 UHPC/dsh 那两次的区别：**这里没有「跑不起来」也没有「被拒加载」** ——

## 总目标（迭代结束时应当成立）

1. `requires-python` 抬到 3.10（或 3.9，取决于用户的方案选择），CI 矩阵同步，
   跑在受支持的解释器上
2. 被 3.8 锁住的依赖上限重新评估并更新（PySide6 / pyinstaller / pytest / docx / pypdf）
3. 条款库有**可机检的复核元数据**（来源日期 + 复核状态），并有守门
4. `CHANGELOG.md` 存在，v1.0.0 → v2.0.0 的变更可读
5. **314 tests 仍全绿** + `sfc bench` 仍 `all_pass: true` + `sfc selfcheck` 通过
6. 新版 exe 用**新解释器**重建并发布（v2.0.0）

> ⚠️ 目标 1 对 pip 用户是**破坏性变更**，所以版本号必须是 **2.0.0**（不是 1.1.0）。
> 这一点已在 `README.md` 的决策表里等用户拍板。

## 每批的门禁

```bash
cd /d D:\ProgramData\zcode\10-6-scaffold-formwork-checker

# 1) 测试（314 是基线，不许少）
.venv/Scripts/python -m pytest tests -q          # 期望 314 passed

# 2) 自检与基准

# 4) 打包红线（批次 2）
python -m PyInstaller tools/sfc.spec --noconfirm    # 走 spec，不手写数据路径
python tools/build_exe.py --check                   # 禁区扫描 + sha256 对账，期望 BUILD_CHECKS_OK

# 5) 脱敏（批次 4）
python tools/desensitize_audit.py                # 全 0

# 6) README 产品页标尺（批次 4）
py "%USERPROFILE%\.agents\skills\ai-tool-release-publish\scripts\check_readme_gate.py" . --strict   # exit 0
```

**判定标准**
- 批次 1 门禁：新解释器干净 venv 下 `[dev]`/`[dev,gui]`/`[dev,build]` 三种 extras 各跑一次全绿
- 批次 2 门禁：`BUILD_CHECKS_OK` + 干净冒烟四连 + dist 移出仓库树仍能跑
- 批次 3 门禁：**4 份规范现行性各有结论与证据** + 条款库复核元数据可机检（新测试进 CI）
- 批次 4 门禁：README 门禁 exit=0 + CHANGELOG 存在 + 发布后重新 clone 仍全绿

## 范围边界（本次迭代不做）

- **不改任何判定逻辑、公式、数值**（除非批次 3.1 核实到规范确已更新——那要单开决策并说明影响面）
- **不动冻结数据**：`data/examples/`（13 例真值）、`data/synthetic/`（12 份 fixtures）
  —— 它们被 314 个测试与 bench 锁住，改一个字节都要走生成器 + 重生成 + 台账更新
- 不改 CLI 退出码口径（0/1/2 是 M0 就锁进测试的契约）
- 不新增验算模块（碗扣/盘扣/附着式是 plan 里留的扩展位，本次不开）
- 不加 LLM 通路（首期零 LLM 是赛题硬要求，plan/06 #8）
- 不动 `data/knowledge/raw/`（版权红线，已在 .gitignore）

## 三条方法论提醒

1. **「测试绿」不等于「能交付」**。这个仓库的历史就证明了：M6 CI 首跑才发现 docx 冻结 fixture
   随平台漂移（决策 #33）。批次 1 改了 5 个依赖的大版本，**必须重建 exe 并真跑一遍**，
   不能只跑 `pytest`。
2. **先查规范现行性，再动其他**。批次 3.1 的结论可能推翻批次 3 其余项甚至批次 1 的优先级
   —— 所以它是「先做、早做」的事，不是收尾动作。
3. **「有限制」和「不表态」是两件事**。D4 的问题不是条款库错了，而是**没有任何机制会告诉你它该复核了**。
   补这个机制的成本很小（加字段 + 一个守门测试），但它把「靠人记得」变成「机器会报」。
