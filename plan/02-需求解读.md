## 2. FR 功能清单（P0=首期必做，P1=首期尽量，P2=扩展）

### A. 安全验算模块（题目 §二.1，全部 P0）

| FR | 名称 | 说明 | 依据规范 |
|---|---|---|---|
| FR-1 | 验算参数卡输入 | 步距/纵距/横距、钢管规格、连墙件布置（两步三跨）、荷载取值、搭设高度；参数合法性范围校验（超范围即拒收） | — |

| FR-5 | 连墙件强度与稳定验算 | 风荷载作用力 + 约束力（数值待核对）→ 强度/稳定双校核 | JGJ 130-2011（条款号待核对） |

| FR-7 | 模板支架立杆稳定性验算 | 模板支架荷载组合（模板及支架自重+新浇混凝土+钢筋+施工荷载）下的立杆稳定 | JGJ 162-2008（条款号待核对） |

## 3. 非功能需求

| NFR | 要求 |
|---|---|
| NFR-1 离线 | 全功能断网可用；报告/页面 0 外链 |
| NFR-2 平台 | Windows 桌面为主（exe 交付）；CLI/核心引擎跨平台（CI ubuntu+windows） |
| NFR-3 可复现 | 基准零 API、固定 seed、落盘产物无时间戳、字节冻结 fixtures 位级一致 |
| NFR-4 可信 | 结论必须挂依据条款；无出处的数值不得以确定语气入库或写进结论 |
| NFR-5 可扩展 | 新增验算模块/新增危大清单条目=加数据不改引擎；类目隔离门控防跨类目误查 |
| NFR-6 性能 | 单方案解析+核查秒级；基准全套分钟级 |

## 4. 边界与非目标（防 scope 失控，承接题目 §六）

- **不做**：任何图像/点云/图纸识图输入（零识图路线）；碗扣式（JGJ 166-2008）/盘扣式（JGJ/T 231-2021）/附着式升降脚手架的**验算**（分级清单可含其判定条目，计算留扩展）；吊篮；真实工程数据（算例=规范/教材+合成方案）。
- **免责红线**：定位=辅助验算与分级工具，不替代专项施工方案编制、论证与审批；所有导出报告强制免责声明。
- **版权红线**：规范/文件全文 PDF 只存本地 `data/knowledge/raw/`（不入公开仓）；入仓条款库=要点+条款号+出处（渠道+获取日期）+status 字段，规避全文转载。
- **品牌隔离**：不复制系列前作代码；公开文档不提其余项目业务领域（发布前复核系列表述的公开性，见 05 §M6）。

## 5. 验收指标（对齐赛题评分表 §四）

| 赛题指标 | 本项目量化目标 | 验证方式 |
|---|---|---|
| 验算算例通过率 | 100%（规范/教材算例真值库，容差比对） | `sfc bench --suite examples`，M4 达标并锁定 |
| 方案核查检出率 | 每类注入缺陷 100% 检出 | 合成方案生成器配对评测 |
| 方案核查误报率 | 0（干净方案 0 误报） | 同上，配对含"干净对照组" |
| 危大分级判定准确率 | 100%（清单条目×边界值±ε 用例） | 分级判定真值用例表 |
| 解析 F1 | ≥0.95（字段级 P/R/F1） | 生成器真值 vs 方案参数卡 |
| 离线即用 | 报告/页面 0 外链断言测试 | 守门测试（HTML 无 http 外链、docx 无 External 关系） |
| 测试与 CI | 全绿 + 四矩阵 CI | pytest + GitHub Actions |
