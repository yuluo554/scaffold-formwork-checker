# 模拟赛题：脚手架与模板支架安全验算及危大分级工具（施工安全领域，规范驱动桌面应用）

> **性质**：自拟模拟赛题（体例对标研究生大赛揭榜赛道赛题说明），与 structural-strengthening-checker 同模式：**规范公式编码（结论逐条挂条款号）+ 专项方案文本核查 + 危大分级判定 + 算例真值基准**，Windows 桌面程序（PySide6 + PyInstaller exe，GitHub Release 附安装包），**零识图路线**。
> **目标产出**：GitHub 公开仓库 `scaffold-formwork-checker`。
> **题目定稿日期**：2026-10-06

## 一、赛题介绍

脚手架与模板支架坍塌是房屋市政工程施工中的高发事故类型——JGJ 130-2011《建筑施工扣件式钢管脚手架安全技术规范》修订的背景正是"施工现场高大支架和模板工程数量增多、事故频发"。监管侧，《危险性较大的分部分项工程安全管理规定》（住建部令第 37 号）及其配套通知（建办质〔2018〕31 号）要求：**搭设高度 24m 及以上的落地式钢管脚手架属危大工程，必须编制专项施工方案；50m 及以上属超过一定规模，必须组织专家论证**——每份专项方案都必须附安全验算书。

行业现状痛点：①验算依赖商业安全计算器（品茗类产品）闭源收费、计算过程不透明；②专项方案文本与验算书"两张皮"——方案中的搭设参数（步距、连墙件间距、剪刀撑）与计算书取值不一致，人工核对难；③方案是否达到危大/超规模门槛、是否需专家论证，靠经验判断、漏判时有发生。

本题要求开发一款脚手架与模板支架安全验算及危大分级工具：规范公式验算计算器（结论挂 JGJ 130-2011 / JGJ 162-2008 条款号）+ 专项方案文本参数核查 + **危大/超规模分级判定器（挂 37 号令与 31 号文清单条款）** + 验算书导出，全离线运行、内置算例真值基准。

## 二、任务要求

### 1）安全验算模块（桌面计算器核心，首期5个）

- **扣件式钢管脚手架立杆稳定性验算**（不组合风荷载 / 组合风荷载两种工况）；
- **纵/横向水平杆抗弯强度与挠度验算**；
- **连墙件强度与稳定验算**；
- **立杆地基承载力验算**；
- **模板支架立杆稳定性验算**（JGJ 162-2008）。

交互：输入参数卡（步距/纵距/横距、钢管规格、连墙件两步三跨布置、荷载取值、搭设高度）→ 输出验算应力比/限值比、结论、**逐条依据条款号**。纪律：公式、构件截面特性（φ48.3×3.6 钢管面积/回转半径等）、容许挠度、构造限值（步距上限、连墙件竖向间距等）全部以规范原文核对后入库（status 字段），未核对条文不得进入计算路径。

### 2）专项方案文本核查（规则引擎，非 CV）

- 输入：脚手架/模板专项施工方案 docx/PDF **文本**；
- 解析为"方案参数卡"：搭设高度、步距/纵距/横距、连墙件布置、剪刀撑设置、钢管规格与材质、荷载取值；
- 核对：参数 vs 规范构造限值（JGJ 130-2011 构造章节）、**方案参数 vs 验算书取值一致性**（两张皮检测），异常三级判定，每条挂条款出处与原文摘录。

### 3）危大分级判定器（政策亮点）

- 输入：工程类型与关键参数（如落地式钢管脚手架搭设高度）；
- 按 37 号令与 31 号文清单判定：非危大 / 危大（需专项方案，施工单位审核+总监审查）/ **超过一定规模（必须专家论证）**，输出判定依据（文件+条款+阈值原文摘录）；
- 判定阈值清单化（如落地式钢管脚手架 24m/50m 两档），逐条挂原文核对。

### 4）验算书与核查报告导出

docx（计算过程、依据条款、结论、编制/审核签署栏），带免责声明：**辅助验算与判定工具，不替代专项施工方案论证与审批**。

### 5）内置评测基准（零 API 依赖）

- **算例真值库**：规范条文算例与施工计算教材算例（数值+来源登记）JSON 化入库，容差比对（目标通过率 100%）；参数扫描回归锁定；
- **文本核查**：合成专项方案生成器（python-docx，固定 seed）植入已知错误（步距超限、漏剪刀撑、漏连墙件、验算书与方案参数不一致、应专家论证未标注），检出率/误报率（目标误报 0）。

## 三、提交材料

1. 桌面应用（PySide6），PyInstaller 打包 Windows exe；2. 核心代码框架（GitHub 公开仓库，含公式引擎、分级判定器与自评基准）；3. 技术报告；4. 算例库与合成方案数据集（含真值与来源台账）；5. GitHub Release：exe 安装包 + 演示 GIF/截图。

## 六、边界与非目标（防 scope 失控）

- **不做**：任何图像/点云输入；碗扣式/盘扣式/附着式升降脚手架首期不做（扩展项，JGJ 166-2008、JGJ/T 231-2021 留档）；吊篮；真实工程数据（算例=规范/教材+合成方案）。
- **免责红线**：辅助验算与分级定位，不替代专项施工方案编制论证与审批；报告强制免责声明。
- **条文纪律**：公式、截面特性表、构造限值、危大阈值全部以文件原文核对后入库（编号+条款+渠道+status）；查不到显式标"待核对"。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
