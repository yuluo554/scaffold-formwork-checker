## 关键纪律（速记，详见各文档）

- 条文数值未经原文核对（status）不得进入计算路径；无出处的数值不得作为基准真值
- 规范全文只存本地 `data/knowledge/raw/` 不入公开仓（版权红线）；入仓=要点+条款号+出处
- 数值结论永远来自确定性规则，零 LLM 通路；基准零 API、固定 seed、字节冻结
- CLI/GUI 消费同一引擎 API（单一事实源）；退出码 0/1/2 已锁进测试
- 发布前：系列表述公开性复核 + 脱敏扫描（见 05 §M6 发布门）
