# scaffold-formwork-checker 项目计划总览

**项目**：脚手架与模板支架安全验算及危大分级工具（土木工程·施工安全领域，Windows 桌面程序，零识图路线）
**方法论**：ai-tool-project-sprint；与 structural-strengthening-checker 同模式（公式引擎+文本核查+分级判定+算例真值基准）
**项目系列**：①建造（已发布）②电力 ③医疗 ④招投标 ⑤食品（Web）⑥发票台账 ⑦简历人才库 ⑧结构加固（桌面）⑨钢结构验算（桌面）→ ⑩本项目（施工安全，桌面）
