# data/ 数据台账

> 规则（ai-tool-project-sprint 阶段1）：每份数据登记来源与许可；规范条目挂出处+status；程序化自制带真值数据是核心资产（固定 seed 可复现，可注入已知缺陷做配对评测）。`_private/` 目录不入仓。
> **M1 起执行**：登记表逐文件登记（sha256=入仓文件指纹，重生成后同步更新本表）。

## 目录结构

| 目录 | 内容 | 入仓 |
|---|---|---|
| `knowledge/raw/` | 规范/文件原文全文（HTML/表格/公式原图） | **否**（版权红线，gitignore；sha256 登记本表"原文存档"节） |
| `knowledge/clauses/` | 条款库 JSON（要点+条款号+出处+status）+ 公式表 + 阈值表 + 危大阈值清单 | 是 |
| `examples/` | 算例真值库（逐例登记来源，tools/gen_examples.py 复算断言） | 是 |
| `synthetic/` | 合成专项方案字节冻结 fixtures + 真值（禁止手改；tools/gen_synthetic.py 固定 seed 重生成） | 是 |
